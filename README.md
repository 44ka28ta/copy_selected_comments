# Copy Selected Comments

Copy selected comments from specified file.

## Prerequisite

```bash
pip3 -m venv .venv
pip3 install -r requirements.txt
```

## Build

```bash
python3 -m build
pip3 install -e .
```

## Run

```bash
python3 -m copy_selected_comments.gui
```
